🔌Setup Guide
MISP: Set MISP_URL and MISP_API_KEY in .env
CIRCL: Public endpoints work without auth. Credentials optional for private feeds.
FS-ISAC: Membership required. Set FSISAC_API_URL and FSISAC_API_KEY
OpenCTI: Set OPENCTI_URL and OPENCTI_TOKEN to activate enrichment connector
After setting credentials, restart the server and re-run the pipeline.
